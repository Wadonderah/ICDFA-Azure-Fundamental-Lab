# Implementation Notes

The project was prepared in the supplied Linux-only offline ICDFA simulator. Simulator state was used only to demonstrate the four laboratory boundaries. The final evidence log and risk register were completed, the storage role was corrected to a storage-account scope, the recovered file was validated against the original hash, the local port was confirmed closed, and assurance and audit checksums were verified.

The repository intentionally excludes `workspace/`, private key files, environment files, Python cache files, and compiled Python artifacts. `recovered/`, `screenshots/`, and `evidence/` are student evidence and remain included.
